# Number Guessing Game

A command-line number guessing game built with Python.

## Description

A simple CLI game where the player attempts to guess a randomly generated number. After each guess, the program provides feedback to help the player find the correct number.

## Features

- Random number generation
- Feedback indicating whether a guess is too high or too low
- Tracking the number of attempts
- Interactive command-line gameplay

## Getting Started

### Prerequisites

- Python 3 installed

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BrianChen809/Number-Guessing-Game.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Number-Guessing-Game
   ```

### Usage

Run the game using:

```bash
python guessing_game.py
```

Follow the prompts in the terminal to play.
